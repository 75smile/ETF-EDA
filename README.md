# 네이버 ETF 분석

네이버 금융 데이터를 활용해 ETF의 기본 정보를 확인하고, 수익률과 거래량 등 주요 지표를 탐색하는 프로젝트입니다.

## 분석 내용

- ETF별 가격 및 거래량 비교
- 기간별 수익률과 변동성 분석
- 관심 ETF의 주요 특징 시각화

## 목적

ETF 데이터를 바탕으로 시장 흐름을 살펴보고, 투자 판단에 참고할 수 있는 기초 분석 결과를 정리합니다.

> 본 프로젝트의 분석 결과는 투자 권유가 아니며, 투자 판단의 참고 자료로만 활용하시기 바랍니다.

## ETF 대시보드

`dashboard`에는 네이버 금융 ETF 데이터를 실시간으로 조회하는 반응형 HTML 대시보드가 포함되어 있습니다.

```powershell
cd dashboard
node scripts/preview.mjs
```

실행 후 `http://127.0.0.1:4173`에서 확인할 수 있습니다. 상세한 기능과 빌드 방법은 `dashboard/README.md`를 참고하세요.
